# 输入模拟

虚数精灵可以在**软件、系统、驱动、硬件**等不同层面产生键盘与鼠标输入。各层面的实现思路不同，适用场景也各有侧重，你可以随时切换，而无需修改已有的程序。

## 方式比较

| 层面 | 模拟方式 | 适用对象 | 说明 |
| :--- | :--- | :--- | :--- |
| 软件层 | PostMessage | 键盘、鼠标 | 后台方式：输入直接发送给指定窗口，不会占用或移动你正在使用的键鼠 |
| 软件层 | ProcessInjection | 键盘、鼠标 | 后台方式：输入在目标程序内部产生，对不响应窗口消息的程序同样有效 |
| 系统层 | Standard | 键盘、鼠标 | 前台方式：与真人操作一致，兼容性最好，也是默认方式 |
| 驱动层 | Driver | 键盘、鼠标 | 前台方式：输入由驱动层产生，特征更接近真实硬件设备 |
| 硬件层 | KmBoxNet | 键盘、鼠标 | 由网络连接的外部设备产生输入，可与本机分开部署 |
| 硬件层 | Makcu | 仅鼠标 | 由串口连接的外部设备产生输入，适合就近外接 |

## 如何选择

- **不希望打断自己的操作**：选择软件层的 PostMessage 或 ProcessInjection，整个过程鼠标指针不会移动，也不会真正按下按键。
- **不确定该用哪一种**：保持默认的系统层 Standard 即可。
- **希望输入特征更接近真实设备**：选择驱动层的 Driver。
- **需要远程或跨设备操作**：选择硬件层的 KmBoxNet 或 Makcu。

## 使用说明

- 在「设置」中可以为键盘、鼠标（或二者一起）分别配置模拟方式，键盘与鼠标不要求使用同一种方式。
- 不同方式的选项略有差异：软件层方式需要指定目标窗口，硬件层方式需要填写设备地址或选择串口。
- 切换方式后，已有程序无需改动，节点会按新的方式执行。
- 选择硬件层方式前，请先连接好对应的外部设备。
