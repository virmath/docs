# 创建视频流（窗口）

**节点类型**：`node-type:/Image/CreateVideoStreamFromWindow`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 窗口句柄 | 整数 | 窗口句柄 | 视频流 | 视频流 | 视频流 |
| 绘制边框 | 布尔 | 绘制边框 |  |  |  |

## 作用

从窗口创建窗口采集视频流对象。

按窗口句柄采集指定窗口画面；绘制边框 为真时会在源窗口上绘制高亮边框（可用于提示用户正在采集该窗口画面）。
