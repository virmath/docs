# 绘制文本

**节点类型**：`node-type:/Image/DrawText`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 源图像 |  |  |  |
| 文本 | 字符串 | 文本 |  |  |  |
| 位置 | 二维整数向量 | 位置 |  |  |  |
| 字体大小 | 浮点数 | 字体大小 |  |  |  |
| 颜色 | 整数 | 颜色 |  |  |  |
| 粗细 | 整数 | 粗细 |  |  |  |

## 作用

在图像上绘制文本。

可指定字体大小、颜色和粗细；非字符串输入会先转为字符串。在原图上原地绘制。
