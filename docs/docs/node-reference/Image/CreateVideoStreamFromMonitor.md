# 创建视频流（显示器）

**节点类型**：`node-type:/Image/CreateVideoStreamFromMonitor`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 显示器句柄 | 整数 | 显示器句柄 | 视频流 | 视频流 | 视频流 |
| 绘制边框 | 布尔 | 绘制边框 |  |  |  |

## 作用

从显示器创建屏幕采集视频流对象。

按显示器句柄采集整个显示器画面；绘制边框 为真时会在源显示器上绘制高亮边框（可用于提示用户正在采集该显示器画面）。
