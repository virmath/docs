# 从视频流读取帧

**节点类型**：`node-type:/Image/ReadFrameFromVideoStream`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 视频流 | 视频流 | 视频流 | 位置 | 二维整数向量 | 图像在屏幕中的位置 |
| RGB | 图像 | 读取到的图像 |  |  |  |

## 作用

从视频流读取一帧图像写入 RGB 目标图像，并输出该帧在屏幕中的位置。

摄像头/文件视频流的位置输出为 (0, 0)；窗口/显示器采集流输出窗口在屏幕上的左上角坐标。
