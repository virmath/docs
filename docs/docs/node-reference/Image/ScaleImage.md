# 缩放图片

**节点类型**：`node-type:/Image/ScaleImage`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 源图像 |  |  |  |
| 已缩放的图像 | 图像 | 缩放输出目标 |  |  |  |
| 缩放因子 | 二维浮点数向量 | 宽高缩放因子 |  |  |  |

## 作用

缩放图像，结果写入 已缩放的图像 目标图像。

缩放因子为二维浮点数向量（宽、高缩放比例）。
