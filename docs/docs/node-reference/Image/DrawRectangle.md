# 绘制矩形

**节点类型**：`node-type:/Image/DrawRectangle`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 源图像 |  |  |  |
| 区域 | 四维整数向量 | 矩形区域 |  |  |  |
| 颜色 | 整数 | 矩形颜色 |  |  |  |
| 粗细 | 整数 | 粗细（负值填充） |  |  |  |

## 作用

在图像上绘制矩形。区域为四维整数向量（x、y、宽、高）；粗细为负值时填充矩形。

在原图上原地绘制（图像对象不变）。
