# 旋转图片

**节点类型**：`node-type:/Image/RotateImage`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 源图像 |  |  |  |
| 已旋转的图像 | 图像 | 旋转输出目标 |  |  |  |
| 角度 | 浮点数 | 旋转角度 |  |  |  |

## 作用

旋转图像，结果写入 已旋转的图像 目标图像。

角度为 90 的整数倍时按 90/180/270 度精确旋转（方向由角度正负决定）。
