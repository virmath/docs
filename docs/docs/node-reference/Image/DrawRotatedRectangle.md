# 绘制旋转矩形

**节点类型**：`node-type:/Image/DrawRotatedRectangle`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 源图像 |  |  |  |
| 中心 | 二维浮点数向量 | 矩形中心 |  |  |  |
| 尺寸 | 二维整数向量 | 模板的宽、高（缩放前），宽或高不大于 0 时不绘制 |  |  |  |
| 缩放 | 浮点数 | 尺寸的缩放倍数 |  |  |  |
| 角度 | 浮点数 | 旋转角度（度），正值表示逆时针 |  |  |  |
| 颜色 | 整数 | 矩形颜色 |  |  |  |
| 粗细 | 整数 | 粗细（负值填充） |  |  |  |

## 作用

在图像上绘制一个可以旋转、缩放的矩形：位置、大小和朝向分别由 中心、尺寸 × 缩放、角度 决定。

在原图上原地绘制（图像对象不变）。
