# 加载图片

**节点类型**：`node-type:/Image/LoadImage`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 路径 | 字符串 | 文件路径 | RGBA | 图像 | RGBA图像 |
|  |  |  | RGB | 图像 | RGB图像 |
|  |  |  | Alpha | 图像 | 由原图Alpha通道构成的单通道图像 |
|  |  |  | 尺寸 | 二维整数向量 | 图像大小 |

## 作用

加载图像文件（支持常见图片格式）。

同时输出 RGBA 图像、RGB 图像、Alpha 单通道图像和尺寸（宽、高）四个输出；文件不存在或格式不支持会运行时报错。
