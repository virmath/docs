# 裁剪图片

**节点类型**：`node-type:/Image/CropImage`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 源图像 |  |  |  |
| 已裁剪的图像 | 图像 | 裁剪输出目标 |  |  |  |
| 区域 | 四维整数向量 | 裁剪区域 |  |  |  |

## 作用

裁剪图像的指定区域。区域为四维整数向量（x、y、宽、高），裁剪结果写入 已裁剪的图像 目标图像。
