# 显示图片

**节点类型**：`node-type:/Image/ShowImage`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 图像 | 图像 | 图像 |  |  |  |
| 等待关闭 | 布尔 | 等待关闭 |  |  |  |

## 作用

在新窗口（Image Viewer）中显示图像。

等待关闭 为真时阻塞等待窗口被关闭后才继续；为假时立即继续。
