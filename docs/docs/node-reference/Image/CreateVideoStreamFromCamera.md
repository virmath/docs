# 创建视频流（摄像头）

**节点类型**：`node-type:/Image/CreateVideoStreamFromCamera`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 索引 | 整数 | 摄像头索引 | 视频流 | 视频流 | 视频流 |
| 宽 | 整数 | 宽度 |  |  |  |
| 高 | 整数 | 高度 |  |  |  |
| 帧率 | 整数 | 帧率 |  |  |  |

## 作用

从摄像头创建视频流对象。按索引、宽、高、帧率配置摄像头，成功后输出视频流对象。
