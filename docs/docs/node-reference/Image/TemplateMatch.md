# 模板匹配

**节点类型**：`node-type:/Image/TemplateMatch`

## 输入输出

| 输入名称 | 输入类型 | 输入说明   | 输出名称     | 输出类型 | 输出说明                              |
| -------- | -------- | ---------- | ------------ | -------- | ------------------------------------- |
| 模板     | 图像     | 模板图像   | 结果         | JSON数组 | 匹配结果                              |
| 掩码     | 图像     | 掩码图像   | 是否匹配     | 布尔     | 找到匹配时为 true，否则为 false       |
| 图像     | 图像     | 源图像     | 首个匹配结果 | JSON对象 | 结果数组的第一个元素；无结果时为 `{}` |
| 置信度   | 浮点数   | 置信度阈值 |              |          |                                       |
| 交并比   | 浮点数   | IOU 阈值   |              |          |                                       |

## 作用

在源图像中搜索模板（模板匹配，归一化相关系数 TM_CCOEFF_NORMED），结果输出为 JSON 数组。

可选掩码模板；按置信度阈值过滤匹配点，再按 IOU 阈值去重。结果数组元素为对象，包含 pos（二维浮点数向量：匹配位置左上角的 x、y 坐标）、center（二维浮点数向量：匹配区域的中心坐标）与 confidence（浮点数）。

没有匹配结果时，“结果”为空数组，“是否匹配”为 false，“首个匹配结果”为 `{}`。“首个匹配结果”在有匹配时与结果数组的第一个元素相同。

## 输出示例

### 结果

「结果」输出连接器（类型：JSON数组）的输出示例：

```json
[
  {
    "pos": { "x": 320, "y": 240 },
    "center": { "x": 370, "y": 265 },
    "confidence": 0.95
  }
]
```

### 是否匹配

「是否匹配」输出连接器（类型：布尔）的输出为：

```text
true
```

没有匹配时为：

```text
false
```

### 首个匹配结果

「首个匹配结果」输出连接器（类型：JSON对象）的输出与结果数组第一项相同：

```json
{
  "pos": { "x": 320, "y": 240 },
  "center": { "x": 370, "y": 265 },
  "confidence": 0.95
}
```

没有匹配时为：

```json
{}
```
