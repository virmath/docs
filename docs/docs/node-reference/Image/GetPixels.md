# 取像素

**节点类型**：`node-type:/Image/GetPixels`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 图像 | 图像 | 源图像 | 颜色1 | 整数 | 像素颜色 |
| 位置1 | 二维整数向量 | 像素坐标 | 颜色2 | 整数 | 像素颜色 |
| 位置2 | 二维整数向量 | 像素坐标 | ... | 整数 | 像素颜色 |
| ... | 二维整数向量 | 像素坐标 | 颜色N | 整数 | 像素颜色 |
| 位置N | 二维整数向量 | 像素坐标 |  |  |  |

## 作用

读取图像上多个指定位置的像素颜色，每个位置输出一个整数颜色值（ARGB 打包）。

坐标越界时自动钳制到图像边缘。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
