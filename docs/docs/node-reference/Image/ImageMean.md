# 图像平均值

**节点类型**：`node-type:/Image/ImageMean`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 图像 | 图像 | 源图像 | 平均值 | 四维浮点数向量 | 像素均值 |
| 掩码 | 图像 | 掩码图像 | 颜色 | 整数 | 均值 |
| 区域 | 四维整数向量 | 同时限定图像与掩码的计算区域；x、y、z、w 全为 0 时使用全图 | | | |

## 作用

计算图像像素均值。

可选掩码：掩码图像为空时计算全图均值，否则仅在掩码区域计算。输出 平均值（四维浮点数向量）与 颜色（均值合成颜色，整数）。

「区域」使用 x、y、z、w 表示左边界、上边界、宽度和高度，并同时作用于图像和掩码。x、y、z、w 全为 0 时使用完整图像；其余情况下 x、y 必须非负且宽度、高度必须大于 0。非空掩码的尺寸必须与图像一致，区域越界时节点报错。
