# 并行任一

**节点类型**：`node-type:/Flow/Parallel/Any`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| -------- | -------- | -------- | -------- | -------- | -------- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| ➡️任务1 | 流程控制 | 并行执行任务1 | 任务索引 | 整数 | 第一个结束的任务编号 |
| ➡️任务2 | 流程控制 | 并行执行任务2 |  |  |  |
| ... | ... | ... |  |  |  |
| ➡️任务N | 流程控制 | 并行执行任务N |  |  |  |

## 作用

并行执行节点。除第一个输入连接器（执行流入口）外，其余输入连接器所连接的控制流会被并行执行，任意一个任务先结束时，其余任务会被中断，节点随后从输出连接器继续执行后续流程。

与 并行全部 不同，本节点不等待所有任务执行完毕，而是以第一个结束的任务为准。

- 任务索引：第一个结束的任务编号（任务1 为 1），可连接后供后续流程判断是哪个任务先结束；若一个任务都没有连接，则输出为 0。
- 任意一个任务出错时，整个节点会失败，程序在该节点处终止，其余任务会被中断。
- 被中断的任务不会再执行后续节点；若它正在执行某个节点，会先等该节点执行完毕再停止。
- 中断只表示不再继续执行，被中断任务在此之前产生的效果（如修改变量、模拟输入、写文件）不会回滚。

变长节点：连接器数量可增减，可通过界面 +/− 或 CLI `program node connector add/delete` 增减并行数。
