# 并行全部

**节点类型**：`node-type:/Flow/Parallel/All`

## 输入输出

| 输入名称 | 输入类型 | 输入说明         | 输出名称 | 输出类型 | 输出说明   |
| -------- | -------- | ---------------- | -------- | -------- | ---------- |
| ➡️        | 流程控制 | 执行流入口       | ➡️        | 流程控制 | 执行流出口 |
| ➡️任务1   | 流程控制 | 并行执行任务1 |          |          |            |
| ➡️任务2   | 流程控制 | 并行执行任务2 |          |          |            |
| ...   | ... | ... |          |          |            |
| ➡️任务N   | 流程控制 | 并行执行任务N |          |          |            |

## 作用

并行执行节点。除第一个输入连接器（执行流入口）外，其余输入连接器所连接的控制流会被并行执行，待全部执行完毕后，节点才从输出连接器继续执行后续流程。

变长节点：连接器数量可增减，可通过界面 +/− 或 CLI `program node connector add/delete` 增减并行数。
