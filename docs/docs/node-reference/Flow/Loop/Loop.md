# 循环

**节点类型**：`node-type:/Flow/Loop/Loop`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 间隔（毫秒） | 整数 | 间隔（毫秒） |  |  |  |
| 🔄循环体 | 流程控制 | 循环体入口 |  |  |  |

## 作用

无限循环节点。循环体执行完后按 间隔（毫秒）限速再进入下一轮，直到被 退出循环 跳出。

循环体为空时直接跳过该节点。
