# 计次循环

**节点类型**：`node-type:/Flow/Loop/ForLoop`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 启始索引 | 整数 | 起始索引 |  |  |  |
| 循环次数 | 整数 | 循环次数 |  |  |  |
| 索引变量名 | 字符串 | 索引变量名 |  |  |  |
| 间隔（毫秒） | 整数 | 间隔（毫秒） |  |  |  |
| 🔄循环体 | 流程控制 | 循环体入口 |  |  |  |

## 作用

计次循环节点。从 起始索引 开始，按 循环次数 依次执行循环体，每轮之间按 间隔（毫秒）限速。

循环体内的 获取值 节点可通过 索引变量名 读取当前循环索引。若起始索引大于结束索引（起始索引 + 循环次数 − 1），则循环体一次都不执行。
