# 分支

**节点类型**：`node-type:/Flow/Branch`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 程序执行流出口 |
| 如果 | 布尔 | 条件判断 |  |  |  |
| ➡️ | 流程控制 | 满足条件时执行此控制流 |  |  |  |
| 另外如果 | 布尔 | 条件判断 |  |  |  |
| ➡️ | 流程控制 | 满足条件时执行此控制流 |  |  |  |
| ... | ... | ... |  |  |  |
| 另外如果 | 布尔 | 条件判断 |  |  |  |
| ➡️ | 流程控制 | 满足条件时执行此控制流 |  |  |  |
| ➡️否则 | 流程控制 | 满足条件时执行此控制流 |  |  |  |

## 作用

条件分支节点。按输入顺序依次判断 如果（If）/ 另外如果（Else If）条件：条件为真时执行其后的控制流分支并结束判断；所有条件都不满足时执行最后的 ➡️否则 分支。

变长节点：连接器数量可增减，可通过界面 +/− 或 CLI `program node connector add/delete` 增减 另外如果 分支（每次增减一对 布尔条件 + 控制流 连接器）。
