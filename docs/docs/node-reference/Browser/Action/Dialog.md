# 处理对话框

**节点类型**：`node-type:/Browser/Action/Dialog`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 结果描述 |
| 接受 | 布尔 | 是否接受对话框 |  |  |  |
| 提示文本 | 字符串 | 输入框类对话框的文本 |  |  |  |

## 作用

处理页面弹出的 `alert` / `confirm` / `prompt` / `beforeunload` 对话框。对话框未处理时，其它页面操作会被阻塞，因此需要及时处理。

「提示文本」只在 `prompt` 对话框接受时生效。
