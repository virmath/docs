# 输入文本

**节点类型**：`node-type:/Browser/Action/Type`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 输入结果 |
| 目标 | 字符串 | 元素引用或选择器 |  |  |  |
| 文本 | 字符串 | 要输入的文本 |  |  |  |
| 清空 | 布尔 | 输入前是否清空原有内容 |  |  |  |
| 逐字输入 | 布尔 | 是否逐字输入 |  |  |  |
| 提交 | 布尔 | 输入后是否按回车 |  |  |  |

## 作用

向输入框等元素输入文本。目标写法与「点击元素」一致（`@e3` 引用或 `text=`/CSS/XPath 选择器）。

使用**元素引用**时支持全部选项（清空/逐字输入/提交）。使用**选择器**时只执行填充，不支持逐字输入与提交回车。
