# 拖拽

**节点类型**：`node-type:/Browser/Action/Drag`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 拖拽结果 |
| 起点 | 字符串 | 被拖拽元素的引用 |  |  |  |
| 终点 | 字符串 | 目标位置的元素引用 |  |  |  |

## 作用

把一个元素拖到另一个元素上（拖拽排序、拖到上传区等）。

「起点」「终点」都只支持元素引用（如 `@e3`），请先执行「页面快照」节点拿到引用后再填。拖拽走浏览器的物理指针输入，会触发页面的 dragover / drop 事件。
