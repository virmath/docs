# 悬停元素

**节点类型**：`node-type:/Browser/Action/Hover`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 悬停结果 |
| 目标 | 字符串 | 元素引用 |  |  |  |

## 作用

把鼠标移动到指定元素上，用于触发 hover 才出现的菜单、提示、下拉等。

「目标」只支持元素引用（如 `@e3`），请先执行「页面快照」节点拿到引用后再填。移动后会自动补一次页面快照，结果里包含最新引用。
