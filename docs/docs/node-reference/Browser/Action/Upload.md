# 上传文件

**节点类型**：`node-type:/Browser/Action/Upload`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 上传结果 |
| 文件路径 | 字符串 | 待上传的文件，每行一个 |  |  |  |

## 作用

给页面上已经弹出的文件选择框指定文件。

使用顺序：先用「点击元素」点一下 `<input type="file">` 或上传按钮（浏览器会弹出文件选择框并挂起），紧接着执行本节点填入路径。每行一个路径，必须位于「启动浏览器」节点设置的允许目录内；如果选择框允许多选，可以填多行。
