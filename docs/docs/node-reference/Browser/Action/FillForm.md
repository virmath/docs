# 填写表单

**节点类型**：`node-type:/Browser/Action/FillForm`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 填写结果 |
| 表单字段 | 字符串 | JSON 数组，逐项描述字段 |  |  |  |

## 作用

一次填写多个字段（文本框、复选框、单选框、下拉框、滑块），比逐个「输入文本 + 选择选项」更快，出错时也会按顺序报告每个字段的结果。

「表单字段」是 JSON 数组，每项格式：

```json
[
  {"target": "@e3", "name": "用户名", "kind": "textbox", "value": "admin"},
  {"target": "@e4", "name": "记住我", "kind": "checkbox", "value": "true"},
  {"target": "@e5", "name": "城市", "kind": "combobox", "value": "上海"}
]
```

- `target`：元素引用（只支持 `@e3` 这种引用），必填。
- `name`：字段名，只用于日志，可省略。
- `kind`：`textbox`（默认）、`checkbox`、`radio`、`combobox`、`slider`。
- `value`：要写入的值；复选框填 `true`/`false`。

字段按数组顺序填写，密码类字段的写入进度会在结果里说明。
