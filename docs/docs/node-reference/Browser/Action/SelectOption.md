# 选择选项

**节点类型**：`node-type:/Browser/Action/SelectOption`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 结果描述 |
| 目标 | 字符串 | 元素引用 |  |  |  |
| 值 | JSON数组 | 要选择的选项值或标签 |  |  |  |

## 作用

在下拉框（`<select>`）中选择选项，可一次选择多个值（多选下拉框）。值的匹配顺序是选项的值（value）优先，未命中时按显示标签匹配；数组为空时清空已选项。

该节点只支持 `@e3` 形式的元素引用作为目标（不支持选择器）。
