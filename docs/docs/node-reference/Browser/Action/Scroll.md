# 滚动

**节点类型**：`node-type:/Browser/Action/Scroll`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 滚动结果 |
| 目标 | 字符串 | 元素引用（可空） |  |  |  |
| 垂直偏移 | 浮点数 | 滚动像素（正数向下） |  |  |  |

## 作用

滚动页面，有两种用法：

- 「目标」填写元素引用（如 `@e3`）：把该元素滚动到可见区域（只支持元素引用，不支持选择器）。
- 「目标」留空：按「垂直偏移」滚动视口，正数向下、负数向上；此时偏移不能为 0。

滚动后会自动补一次页面快照，结果里包含最新引用。
