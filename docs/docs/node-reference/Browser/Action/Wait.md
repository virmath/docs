# 等待

**节点类型**：`node-type:/Browser/Action/Wait`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 等待结果 |
| 秒 | 浮点数 | 等待时长（秒），0 表示不使用 |  |  |  |
| 文本出现 | 字符串 | 等待该文本出现 |  |  |  |
| 文本消失 | 字符串 | 等待该文本消失 |  |  |  |
| 超时 | 整数 | 等待超时（毫秒） |  |  |  |

## 作用

等待页面达到指定状态：等待固定时长、等待文本出现，或者等待文本消失，三者可以同时使用（全部满足才继续）。

三个条件至少要填写一个，否则报错。等待超时或程序被停止时，本次等待会被中断。注意「超时」不应大于「启动浏览器」节点里设置的默认操作超时。
