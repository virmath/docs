# 按键

**节点类型**：`node-type:/Browser/Action/PressKey`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 按键结果 |
| 目标 | 字符串 | 元素引用（可空） |  |  |  |
| 按键 | 字符串 | 按键名称 |  |  |  |

## 作用

按下并松开一个按键，或发送组合键。

- 「目标」填写元素引用（如 `@e3`）时，先聚焦该元素再按键；留空表示直接发给页面（适合 `Escape`、`PageDown` 等全局按键）。上游只支持元素引用，不支持 CSS/XPath 选择器。
- 「按键」写法：`Enter`、`Escape`、`Tab`、`ArrowDown`、`Backspace`，组合键用 `+` 连接，例如 `Control+A`、`Shift+Tab`。

常见用法：用「输入文本」填内容后，用本节点发送 `Enter` 提交。
