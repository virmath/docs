# 拖放数据

**节点类型**：`node-type:/Browser/Action/Drop`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 拖放结果 |
| 目标 | 字符串 | 放置位置的元素引用 |  |  |  |
| 文件路径 | 字符串 | 拖入的文件，每行一个 |  |  |  |
| 拖放数据 | 字符串 | JSON 对象，键为 MIME 类型 |  |  |  |

## 作用

模拟「把文件或文本拖到某个元素上」，和「拖拽」节点不同：这里不移动已有元素，而是直接向目标元素投放数据。

- 「目标」只支持元素引用（如 `@e3`）。
- 「文件路径」每行一个路径，必须位于「启动浏览器」节点设置的允许目录内。
- 「拖放数据」是 JSON 对象，例如 `{"text/plain": "hello"}`；键是 MIME 类型。不需要拖文件时可以只填它。

「文件路径」和「拖放数据」至少要填一个。
