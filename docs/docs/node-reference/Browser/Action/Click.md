# 点击元素

**节点类型**：`node-type:/Browser/Action/Click`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 点击结果 |
| 目标 | 字符串 | 元素引用或选择器 |  |  |  |
| 双击 | 布尔 | 是否双击 |  |  |  |

## 作用

点击指定元素。目标支持两种写法：

- **元素引用**：`@e3`（推荐，来自「页面快照」节点）；
- **选择器**：CSS 选择器（如 `#submit`）、`text=登录`（支持 `/正则/`）、`xpath=//button[1]`。

「目标」输入框右侧带有元素选择器按钮，可以直接在编辑器打开的预览浏览器里挑选元素（详见[浏览器](../../Browser.md)）。

点击会先严格定位元素并等待其可操作（可见、位置稳定、能接收指针事件、未禁用），匹配到多个元素时会报错（不会随便点第一个），随后通过浏览器物理输入点击。
