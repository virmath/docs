# 启动浏览器

**节点类型**：`node-type:/Browser/Session/Launch`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 无头模式 | 布尔 | 是否使用无头模式 | 浏览器会话 | 浏览器会话 | 浏览器会话 |
| 浏览器路径 | 字符串 | 浏览器可执行文件路径 | 浏览器路径 | 字符串 | 实际使用的浏览器路径 |
| 用户数据目录 | 字符串 | 用户数据目录 |  |  |  |
| 启动参数 | JSON数组 | 额外的浏览器启动参数 |  |  |  |
| 默认操作超时 | 整数 | 所有浏览器操作的超时（毫秒） |  |  |  |
| 允许访问的目录 | 字符串 | 限制拖放/上传可使用的文件目录 |  |  |  |

## 作用

启动一个 Chromium 系浏览器（Chrome、Edge、Brave、Chromium 均可）并输出浏览器会话，供后续浏览器节点使用。

浏览器路径留空时自动查找本机已安装的浏览器；找不到时直接报错。启动成功后节点会立刻验证浏览器可用（找不到、启动失败或超时都会在启动节点上报错），并把实际使用的浏览器路径输出到「浏览器路径」。

「用户数据目录」留空时使用临时目录，不会读取或写入用户日常使用的浏览器配置；需要保留登录状态时再指定目录。「允许访问的目录」用于限制拖放、上传文件时可访问的路径范围。

「默认操作超时」同时是后续所有浏览器操作的上限，等待类操作请把它设置得足够大。
