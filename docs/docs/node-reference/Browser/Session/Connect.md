# 连接浏览器

**节点类型**：`node-type:/Browser/Session/Connect`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 连接端点 | 字符串 | CDP 端点地址 | 浏览器会话 | 浏览器会话 | 浏览器会话 |
| 请求头 | 字符串 | 附加请求头（JSON 对象，可空） | 结果 | 字符串 | 实际连接的端点 |
| 超时 | 整数 | 连接超时（毫秒） |  |  |  |

## 作用

连接到一个**已经运行**的浏览器，而不是新启动一个。适合复用用户手动打开的浏览器（已登录的会话、已装好的扩展）。

使用前需要让目标浏览器开放调试端口，例如以

```text
--remote-debugging-port=9222
```

启动，然后「连接端点」填 `http://127.0.0.1:9222`。

「请求头」是 JSON 对象，用于需要鉴权的远程端点，例如 `{"Authorization": "Bearer ..."}`，本地连接留空即可。连接成功后用法与「启动浏览器」完全一致，同样支持「关闭浏览器」节点结束会话。
