# 关闭标签页

**节点类型**：`node-type:/Browser/Session/Tabs/Close`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 结果描述 |
| 索引 | 整数 | 标签页序号（-1 表示当前标签页） |  |  |  |

## 作用

关闭指定序号的标签页，索引为 -1 时关闭当前标签页。
