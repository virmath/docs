# 切换标签页

**节点类型**：`node-type:/Browser/Session/Tabs/Select`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 结果描述 |
| 索引 | 整数 | 标签页序号 |  |  |  |

## 作用

切换到指定序号的标签页（序号来自「列出标签页」）。切换后之前的元素引用失效，需要重新执行「页面快照」。
