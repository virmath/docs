# 新建标签页

**节点类型**：`node-type:/Browser/Session/Tabs/New`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 结果描述 |
| 网址 | 字符串 | 新标签页打开的网址（可空） |  |  |  |

## 作用

新建一个标签页并切换过去，网址留空时打开空白页。新建后之前的元素引用失效，需要重新执行「页面快照」。
