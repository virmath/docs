# 打开网址

**节点类型**：`node-type:/Browser/Navigation/Open`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 导航结果 |
| 网址 | 字符串 | 目标网址 |  |  |  |

## 作用

在当前页面打开指定网址，等待页面加载后返回导航结果描述。网址不能为空；超时或加载失败会报错。

导航会使已有的元素引用（快照中的 ref）失效，跳转后需要重新执行「页面快照」。
