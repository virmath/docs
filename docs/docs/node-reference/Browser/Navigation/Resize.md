# 设置视口

**节点类型**：`node-type:/Browser/Navigation/Resize`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 设置结果 |
| 宽 | 整数 | 视口宽度（像素） |  |  |  |
| 高 | 整数 | 视口高度（像素） |  |  |  |

## 作用

设置浏览器视口的宽高（CSS 像素）。改变视口会影响页面布局与元素坐标，建议在页面操作之前设置。
