# 控制台日志

**节点类型**：`node-type:/Browser/Diagnostics/Console`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 消息 | 字符串 | 控制台日志 |
| 日志级别 | 字符串 | error / warning / info / debug |  |  |  |
| 全部消息 | 布尔 | 是否返回全部历史消息 |  |  |  |

## 作用

读取浏览器控制台的消息，用于排查页面报错、脚本异常。

- 「日志级别」默认 `error`，填 `warning`、`info`、`debug` 可以拿到更多级别（级别越高包含的下级越多）。
- 「全部消息」关闭时只返回自上次读取以来的新消息，打开时返回缓冲区里的全部消息。
