# 请求详情

**节点类型**：`node-type:/Browser/Diagnostics/NetworkRequest`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | 字符串 | 请求详情 |
| 序号 | 整数 | 来自请求列表的序号 |  |  |  |
| 请求部分 | 字符串 | 只看某一部分（可空） |  |  |  |

## 作用

查看某一条网络请求的请求头、请求体、响应头、响应体。

- 「序号」用「网络请求列表」节点输出里的序号。
- 「请求部分」可填 `request-headers`、`request-body`、`response-headers`、`response-body`；留空则四部分都返回。
- 序号来自当前这次页面导航，跳转之后旧序号会失效，需要重新取请求列表。
