# 网络请求列表

**节点类型**：`node-type:/Browser/Diagnostics/NetworkRequests`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 请求列表 | 字符串 | 请求清单 |
| 包含静态资源 | 布尔 | 是否包含图片/CSS/JS |  |  |  |
| 过滤 | 字符串 | 只保留包含该关键字的请求 |  |  |  |

## 作用

列出页面发出的网络请求，每行带有序号，可以直接把序号填到「请求详情」节点里看具体内容。

- 「包含静态资源」默认关闭，只看接口类请求（XHR/fetch/文档），打开后连图片、脚本、样式一起列出。
- 「过滤」按 URL 关键字筛选，可留空。
