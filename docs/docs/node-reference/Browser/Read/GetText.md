# 获取文本

**节点类型**：`node-type:/Browser/Read/GetText`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 文本 | 字符串 | 元素文本 |
| 目标 | 字符串 | 元素引用或选择器 |  |  |  |
| 严格匹配 | 布尔 | 选择器是否必须唯一匹配 |  |  |  |
| 最大字符数 | 整数 | 返回文本的最大长度 |  |  |  |

## 作用

读取指定元素渲染后的文本。目标支持 `@e3` 形式的元素引用，或 `text=`/CSS/XPath 选择器。

「严格匹配」只对选择器生效：开启时，选择器匹配到多个元素会报错。文本超过「最大字符数」时会被截断。
