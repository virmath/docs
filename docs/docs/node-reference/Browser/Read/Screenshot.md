# 截图

**节点类型**：`node-type:/Browser/Read/Screenshot`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 图像 | 图像 | 页面截图 |
| 整页截图 | 布尔 | 是否截取整页 |  |  |  |

## 作用

截取当前页面并输出图像，可直接连到图像处理、AI 推理或保存图像等节点。

「整页截图」关闭时只截取当前视口区域；开启时会滚动拼接整页。图像按 RGBA 四通道输出。
