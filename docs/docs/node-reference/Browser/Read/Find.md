# 查找文本

**节点类型**：`node-type:/Browser/Read/Find`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | JSON值 | 命中的行号数组 |
| 文本 | 字符串 | 要查找的文本或正则 |  |  |  |
| 使用正则 | 布尔 | 是否按正则表达式匹配 |  |  |  |
| 忽略大小写 | 布尔 | 是否忽略大小写 |  |  |  |

## 作用

在页面快照里查找匹配的行，返回命中的行号数组（从 0 开始），配合「页面快照」的文本结果可以看出具体是哪一行。

「使用正则」打开时，「文本」按正则表达式解释（例如 `登录|Sign in`）；「忽略大小写」对两种模式都生效。
