# 页面信息

**节点类型**：`node-type:/Browser/Read/PageInfo`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 页面信息 | JSON值 | `title` 与 `url` |

## 作用

读取当前页面的标题和网址，输出形如 `{"title": "示例", "url": "https://example.com/"}` 的 JSON 对象。

常用于等待跳转、校验是否打开了正确页面，或用「JSON 对象取值」节点取出 `url` 再拼接。
