# 页面快照

**节点类型**：`node-type:/Browser/Read/Snapshot`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 页面快照 | 字符串 | 页面快照 |
| 目标 | 字符串 | 快照的根元素（如 `@e3`），留空表示整个页面 |  |  |  |
| 深度 | 整数 | 快照深度，0 表示不限制 |  |  |  |
| 包含坐标 | 布尔 | 是否包含元素坐标 |  |  |  |
| 最大条目 | 整数 | 最大条目数，0 表示不限制 |  |  |  |

## 作用

输出页面的可访问性快照，每个可交互元素带一个引用（`e1`、`e2`…）。后续的点击、输入等节点可以直接使用这些引用作为「目标」，例如 `@e3`。

引用是会话内的编号：一旦发生导航或者再次执行本节点，之前的引用就会失效，需要使用最新一次快照里的引用。

快照只覆盖主文档：`iframe` 只会作为一个节点出现（其内部元素没有引用），开放 shadow DOM 的内容不在快照中（这类元素请改用 CSS/XPath 选择器定位）。快照反映页面当前状态、包含输入框的值，请把它当作可能包含敏感信息的数据处理。
