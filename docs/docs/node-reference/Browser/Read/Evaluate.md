# 执行 JavaScript

**节点类型**：`node-type:/Browser/Read/Evaluate`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 浏览器会话 | 浏览器会话 | 浏览器会话 | 结果 | JSON值 | 执行结果 |
| 函数 | 字符串 | 要执行的 JavaScript 函数 |  |  |  |
| 目标 | 字符串 | 元素引用（可空） |  |  |  |

## 作用

在页面中执行一段 JavaScript 并返回结果。函数需要写成函数体的形式，例如 `() => document.title`。

「目标」填写元素引用（如 `@e3`）时，函数会在该元素上下文中执行；留空表示在页面上下文执行。返回结果会优先按 JSON 解析，无法解析时按字符串输出。

该节点可以做到选择器/引用无法覆盖的事情（读取存储、修改 DOM、访问页面对象等），请只在可信页面上使用。
