# 枚举显示器

**节点类型**：`node-type:/System/Monitor/EnumerateMonitors`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
|  |  |  | 显示器句柄 | JSON数组 | 所有有效显示器的句柄 |
|  |  |  | 存在显示器 | 布尔 | 是否至少枚举到一个有效显示器 |
|  |  |  | 首个显示器句柄 | 整数 | 第一个显示器句柄；无显示器时为 -1 |

## 作用

枚举当前系统中所有有效显示器并返回显示器句柄。存在主显示器时，主显示器会排在第一位，其余显示器保持系统枚举顺序。

“显示器句柄”和“首个显示器句柄”可直接用于“获取显示器矩形”或“从显示器创建视频流”等需要显示器句柄的节点。

未找到有效显示器时，“显示器句柄”输出空 JSON 数组，“存在显示器”输出 `false`，“首个显示器句柄”输出 `-1`。
