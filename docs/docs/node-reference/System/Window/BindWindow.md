# 绑定窗口

**节点类型**：`node-type:/System/Window/BindWindow`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 窗口句柄 | 整数 | 要绑定的目标窗口句柄 |  |  |  |

## 作用

将指定窗口绑定为当前运行时的目标窗口，供后台键鼠输入和窗口画面读取使用。多次执行时会使用新窗口替换之前的绑定。

当键鼠共享配置已开启，并且输入模拟方式为 PostMessage 或 ProcessInjection 时，后续键鼠操作会使用新绑定的窗口。

当“从视频流读取帧”节点的视频流输入为空时，会使用这里绑定的窗口读取画面。
