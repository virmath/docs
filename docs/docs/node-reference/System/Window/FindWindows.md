# 查找窗口

**节点类型**：`node-type:/System/Window/FindWindows`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 窗口关键字 | 字符串 | 用于匹配窗口标题的关键字 | 匹配句柄 | JSON数组 | 所有匹配窗口的句柄 |
| 使用正则表达式 | 布尔 | 是否将窗口关键字作为正则表达式 | 存在匹配 | 布尔 | 是否至少匹配到一个窗口 |
|  |  |  | 首个匹配句柄 | 整数 | 第一个匹配窗口的句柄；无匹配时为 -1 |

## 作用

查找标题中包含指定关键字的窗口，并返回匹配窗口的句柄。默认按字面量子串匹配；开启“使用正则表达式”后，窗口关键字会作为正则表达式使用。两种模式均区分大小写，将关键字设为空时会匹配所有符合过滤条件的窗口。

正则表达式无效时节点运行报错。如需忽略大小写，可使用 `(?i)` 等正则表达式内联标志。

查找过程会排除程序自身创建的窗口，以及不可见、子窗口、工具窗口和客户区无效的窗口。结果按照系统枚举到窗口的顺序排列，因此“首个匹配句柄”是其中第一个匹配项。

未找到匹配窗口时，“匹配句柄”输出空 JSON 数组，“存在匹配”输出 `false`，“首个匹配句柄”输出 `-1`。
