# 播放音频

**节点类型**：`node-type:/System/Audio/Play`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 音频文件路径 | 字符串 | 音频文件路径 |  |  |  |
| 音量 | 浮点数 | 音量 |  |  |  |
| 等待播放结束 | 布尔 | 是否等待播放结束 |  |  |  |

## 作用

播放指定路径的音频文件，支持常见音频格式，如 MP3、WAV、FLAC、OGG、M4A。

等待播放结束默认为真，此时节点会等待音频播放完毕后继续执行；设为假时节点在开始播放后立即继续执行。程序结束时，正在播放的音频会被终止。
