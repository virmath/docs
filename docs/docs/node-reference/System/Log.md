# 日志

**节点类型**：`node-type:/System/Log`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 格式 | 字符串 | 格式字符串 |  |  |  |
| 参数1 | 字符串 | 格式化参数 |  |  |  |
| 参数2 | 字符串 | 格式化参数 |  |  |  |
| ... | 字符串 | 格式化参数 |  |  |  |
| 参数N | 字符串 | 格式化参数 |  |  |  |

## 作用

按格式模板把参数拼接成消息并输出到日志。模板中的 `{}` 占位符依次被参数值替换。

连接器数量由模板中的 `{}` 数量决定：修改格式值 （`program node connector set`）会自动同步参数连接器；add/delete 会追加/移除一个 `{}` 占位符。

格式连接器为运行时只读（不可连接）。
