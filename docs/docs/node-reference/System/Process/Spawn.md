# 创建

**节点类型**：`node-type:/System/Process/Spawn`

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |

| 参数 | JSON数组 | 命令行参数 |  |  |  |
| 工作目录 | 字符串 | 工作目录 |  |  |  |

| 环境变量 | JSON对象 | 环境变量 |  |  |  |

## 作用

启动外部程序。可指定程序路径、命令行参数（JSON 数组）、工作目录，并可选清空环境变量或传入环境变量映射（JSON 对象）。

程序路径为空、工作目录无效时运行时报错；参数数组中的非字符串元素会被忽略。启动后等待进程结束，输出 结果（布尔值，进程是否成功退出）。
