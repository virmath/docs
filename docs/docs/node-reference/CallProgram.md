# 调用程序

**节点类型**：`node-type:/CallProgram`

> 调用另一个程序的节点。创建时需通过 `node add` 的 `--call-program-id` 参数指定被调用程序。

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 |  | ➡️ | 流程控制 |  |

## 作用

输入/输出连接器由被调用程序的选项（Option）决定：输入选项对应输入连接器，输出选项对应输出连接器；当被调用程序的选项增删时，本节点连接器自动同步。
