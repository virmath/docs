# 设置值（二维浮点数向量）

**节点类型**：`node-type:/Variable/Setter/Vector2Float64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 变量名 | 字符串 | 变量名 |  |  |  |
| 变量值 | 二维浮点数向量 | 要设置的变量值 |  |  |  |

## 作用

把 变量值 写入指定变量（类型：二维浮点数向量）。

变量名 输入指定要写入的变量名，写入后可在同一程序运行期间通过 获取值 节点读取。
