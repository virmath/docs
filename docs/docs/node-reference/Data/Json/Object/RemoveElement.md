# 删除元素

**节点类型**：`node-type:/Data/Json/Object/RemoveElement`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| JSON对象 | JSON对象 | JSON 对象 |  |  |  |
| 键 | 字符串 | 要删除的键 |  |  |  |

## 作用

从 JSON 对象删除指定键（原地修改）；键不存在时不做任何操作。
