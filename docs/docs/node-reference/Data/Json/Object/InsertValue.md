# 插入值

**节点类型**：`node-type:/Data/Json/Object/InsertValue`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| JSON对象 | JSON对象 | JSON 对象 |  |  |  |
| 键 | 字符串 | 键名 |  |  |  |
| JSON值 | JSON值 | 要插入的值 |  |  |  |

## 作用

向 JSON 对象写入键值（原地修改）；键已存在时覆盖原值。
