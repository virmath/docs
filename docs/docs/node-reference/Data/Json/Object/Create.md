# 创建

**节点类型**：`node-type:/Data/Json/Object/Create`

## 输入输出

| 输入名称   | 输入类型  | 输入说明                                     | 输出名称 | 输出类型 | 输出说明           |
| ---------- | --------- | -------------------------------------------- | -------- | -------- | ------------------ |
| JSON字符串 | 字符串    | 用于创建基础 JSON 对象                       | JSON对象 | JSON对象 | 合并后的 JSON 对象 |
| JSON对象   | JSON对象  | 将其键值对合并到基础对象；未连接时视为空对象 |          |          |                    |
| 键N        | 字符串    | 第 N 个动态属性名；未连接或为空时跳过        |          |          |                    |
| 值N        | JsonValue | 第 N 个动态属性值；未连接时写入 null         |          |          |                    |

## 作用

先从 JSON 字符串解析创建一个 JSON 对象，然后合并第二个输入中的键值对，最后按顺序写入动态键值对。

若字符串解析失败或结果不是 JSON 对象，则运行时报错。

重复键采用后写覆盖先写。

变长节点：连接器数量可增减，可通过界面 +/− 或 CLI `program node connector add/delete` 增减。
