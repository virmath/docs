# 插入值

**节点类型**：`node-type:/Data/Json/Array/InsertValue`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| JSON数组 | JSON数组 | JSON 数组 |  |  |  |
| 索引 | 整数 | 插入位置 |  |  |  |
| JSON值 | JSON值 | 要插入的值 |  |  |  |

## 作用

把值插入 JSON 数组的指定索引处（原地修改）。

若索引大于等于当前长度，则追加到末尾。
