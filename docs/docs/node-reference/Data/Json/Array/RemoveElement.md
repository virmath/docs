# 删除元素

**节点类型**：`node-type:/Data/Json/Array/RemoveElement`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| JSON数组 | JSON数组 | JSON 数组 |  |  |  |
| 索引 | 整数 | 移除位置 |  |  |  |

## 作用

移除 JSON 数组指定索引处的元素（原地修改）。

索引越界时不做任何操作。
