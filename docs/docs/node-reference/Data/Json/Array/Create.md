# 创建

**节点类型**：`node-type:/Data/Json/Array/Create`

## 输入输出

| 输入名称   | 输入类型  | 输入说明                                           | 输出名称 | 输出类型 | 输出说明           |
| ---------- | --------- | -------------------------------------------------- | -------- | -------- | ------------------ |
| JSON字符串 | 字符串    | 用于创建基础 JSON 数组                             | JSON数组 | JSON数组 | 合并后的 JSON 数组 |
| JSON数组   | JSON数组  | 将其顶层元素依次追加到基础数组；未连接时视为空数组 |          |          |                    |
| 元素N      | JsonValue | 依次追加到数组末尾；未连接时追加 null              |          |          |                    |

## 作用

先从 JSON 字符串解析创建一个 JSON 数组，然后依次追加第二个输入中的顶层元素，最后按顺序追加所有动态 JsonValue 输入。

若字符串解析失败或结果不是数组，则运行时报错。

第二个输入只展开一层：其中嵌套的 JSON 数组会作为一个元素保留。

变长节点：连接器数量可增减，可通过界面 +/− 或 CLI `program node connector add/delete` 增减。新增但尚未连接的动态输入会以 null 写入对应位置。
