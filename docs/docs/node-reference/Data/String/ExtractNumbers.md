# 提取数值

**节点类型**：`node-type:/Data/String/ExtractNumbers`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 字符串 | 字符串 | 待扫描的文本 | 数值 | JSON数组 | 提取到的数值列表 |

## 作用

从文本中扫描出所有数值，按出现顺序组成 JSON 数组输出。

数值的识别规则：

- 只识别十进制写法：可选的负号 `-`，加上若干数字，之后可跟小数点和若干数字，例如 `-12`、`3.14`。
- 不支持前导加号（`+1`）、省略整数部分（`.5`）、指数形式（`1e3`）和千分位分隔符（`1,234`）。
- 上述不支持的写法会退化为按普通数字分别识别：`+1` 得到 `1`，`.5` 得到 `5`，`1e3` 得到 `1` 和 `3`，`1,234` 得到 `1` 和 `234`。
- `-` 仅在紧跟数字时视为负号，单独的 `-` 会被忽略。

每个数值优先按有符号整数解析；整数解析失败（溢出）或带小数部分时，按双精度浮点数解析，因此数组中可能同时包含整数和浮点数。

文本中没有数值时输出空数组。
