# 字符串清理（字符串 / 清理）

**节点类型**：`node-type:/Data/String/StringTrim`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 字符串 | 字符串 | 字符串 | 结果 | 字符串 | 清理结果 |
| 清理模式 | 整数 | 清理模式 |  |  |  |

## 作用

按清理模式去除字符串两端的空白字符，结果输出为字符串。

清理模式取值：All（默认，去两端）、Start（只去开头）、End（只去结尾）；其余取值不做任何处理。
