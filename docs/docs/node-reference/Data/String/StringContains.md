# 字符串包含（字符串 / 包含）

**节点类型**：`node-type:/Data/String/StringContains`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 字符串 | 字符串 | 源字符串 | 包含 | 布尔 | 判断结果 |
| 子字符串 | 字符串 | 子字符串 |  |  |  |
| 开头匹配 | 布尔 | 开头匹配 |  |  |  |
| 结尾匹配 | 布尔 | 结尾匹配 |  |  |  |

## 作用

判断源字符串是否包含（或开头/结尾匹配）指定子字符串，结果为布尔值。
