# 拆分（四维浮点数向量）

**节点类型**：`node-type:/Data/Vector/Split/Vector4Float64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 四维浮点数向量 | 四维浮点数向量 | 待拆分的向量 | X | 浮点数 | X 分量 |
|  |  |  | Y | 浮点数 | Y 分量 |
|  |  |  | Z | 浮点数 | Z 分量 |
|  |  |  | W | 浮点数 | W 分量 |

## 作用

把四维浮点数向量拆分为 X、Y、Z、W 四个浮点数输出。
