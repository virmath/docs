# 合成（四维整数向量）

**节点类型**：`node-type:/Data/Vector/Combine/Vector4Int64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| X | 整数 | X 分量 | 四维整数向量 | 四维整数向量 | 合成的向量 |
| Y | 整数 | Y 分量 |  |  |  |
| Z | 整数 | Z 分量 |  |  |  |
| W | 整数 | W 分量 |  |  |  |

## 作用

把 X、Y、Z、W 四个整数合成为四维整数向量。
