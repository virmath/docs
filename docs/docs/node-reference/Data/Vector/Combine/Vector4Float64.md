# 合成（四维浮点数向量）

**节点类型**：`node-type:/Data/Vector/Combine/Vector4Float64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| X | 浮点数 | X 分量 | 四维浮点数向量 | 四维浮点数向量 | 合成的向量 |
| Y | 浮点数 | Y 分量 |  |  |  |
| Z | 浮点数 | Z 分量 |  |  |  |
| W | 浮点数 | W 分量 |  |  |  |

## 作用

把 X、Y、Z、W 四个浮点数合成为四维浮点数向量。
