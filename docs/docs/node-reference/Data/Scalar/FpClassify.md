# 浮点数分类

**节点类型**：`node-type:/Data/Scalar/FpClassify`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 值 | 浮点数 | 浮点数 | 非数 | 布尔 | 是否为 NaN |
|  |  |  | 无穷大 | 布尔 | 是否为无穷大 |
|  |  |  | 零 | 布尔 | 是否为零 |
|  |  |  | 次正规数 | 布尔 | 是否为次正规数 |
|  |  |  | 正规数 | 布尔 | 是否为正规数 |

## 作用

对浮点数进行分类，输出 5 个布尔结果：是否为 NaN、无穷大、零、次正规数、正规数。
