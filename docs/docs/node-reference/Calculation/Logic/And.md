# 与

**节点类型**：`node-type:/Calculation/Logic/And`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 布尔 | 输入值 | 结果 | 布尔 | 运算结果 |
| 输入2 | 布尔 | 输入值 |  |  |  |
| ... | 布尔 | 输入值 |  |  |  |
| 输入N | 布尔 | 输入值 |  |  |  |

## 作用

对两个布尔输入执行逻辑与运算（&&），结果为布尔值。

变长节点：输入数量可通过界面 +/− 或 CLI `program node connector add/delete` 增减。
