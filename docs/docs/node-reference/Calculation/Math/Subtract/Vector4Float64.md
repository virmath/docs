# 减（四维浮点数向量）

**节点类型**：`node-type:/Calculation/Math/Subtract/Vector4Float64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 四维浮点数向量 | 操作数输入 | 结果 | 四维浮点数向量 | 逐分量运算结果 |
| 输入2 | 四维浮点数向量 | 操作数输入 |  |  |  |
| ... | 四维浮点数向量 | 操作数输入 |  |  |  |
| 输入N | 四维浮点数向量 | 操作数输入 |  |  |  |

## 作用

从第一个四维浮点数向量的 X、Y、Z、W 分量开始，依次减去后续各向量的对应分量（-），结果输出为四维浮点数向量。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
