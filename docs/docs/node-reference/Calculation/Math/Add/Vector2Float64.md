# 加（二维浮点数向量）

**节点类型**：`node-type:/Calculation/Math/Add/Vector2Float64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 二维浮点数向量 | 操作数输入 | 结果 | 二维浮点数向量 | 逐分量运算结果 |
| 输入2 | 二维浮点数向量 | 操作数输入 |  |  |  |
| ... | 二维浮点数向量 | 操作数输入 |  |  |  |
| 输入N | 二维浮点数向量 | 操作数输入 |  |  |  |

## 作用

按输入顺序对各个二维浮点数向量的 X、Y 分量分别求和（+），结果输出为二维浮点数向量。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
