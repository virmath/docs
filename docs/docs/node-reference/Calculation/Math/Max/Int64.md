# 取最大值（整数）

**节点类型**：`node-type:/Calculation/Math/Max/Int64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 整数 | 操作数输入 | 结果 | 整数 | 运算结果 |
| 输入2 | 整数 | 操作数输入 |  |  |  |
| ... | 整数 | 操作数输入 |  |  |  |
| 输入N | 整数 | 操作数输入 |  |  |  |

## 作用

求整数输入中的最大值，结果输出为整数。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
