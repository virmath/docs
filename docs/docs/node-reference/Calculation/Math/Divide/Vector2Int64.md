# 除（二维整数向量）

**节点类型**：`node-type:/Calculation/Math/Divide/Vector2Int64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 二维整数向量 | 操作数输入 | 结果 | 二维整数向量 | 逐分量运算结果 |
| 输入2 | 二维整数向量 | 操作数输入 |  |  |  |
| ... | 二维整数向量 | 操作数输入 |  |  |  |
| 输入N | 二维整数向量 | 操作数输入 |  |  |  |

## 作用

从第一个二维整数向量的 X、Y 分量开始，依次除以后续各向量的对应分量（/），结果输出为二维整数向量。

任一除数向量的 X 或 Y 分量为 0 时运行时报错。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
