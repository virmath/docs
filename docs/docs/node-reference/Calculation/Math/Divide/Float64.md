# 除（浮点数）

**节点类型**：`node-type:/Calculation/Math/Divide/Float64`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 浮点数 | 操作数输入 | 结果 | 浮点数 | 运算结果 |
| 输入2 | 浮点数 | 操作数输入 |  |  |  |
| ... | 浮点数 | 操作数输入 |  |  |  |
| 输入N | 浮点数 | 操作数输入 |  |  |  |

## 作用

用第一个浮点数输入除以第二个浮点数输入（/），结果输出为浮点数。

除数为 0 时运行时报错。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
