# 与

**节点类型**：`node-type:/Calculation/Bitwise/And`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 整数 | 输入值 | 结果 | 整数 | 运算结果 |
| 输入2 | 整数 | 输入值 |  |  |  |
| ... | 整数 | 输入值 |  |  |  |
| 输入N | 整数 | 输入值 |  |  |  |

## 作用

对两个整数输入按位执行与运算（&），结果输出为整数。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
