# 左移

**节点类型**：`node-type:/Calculation/Bitwise/LeftShift`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 输入1 | 整数 | 输入值 | 结果 | 整数 | 运算结果 |
| 输入2 | 整数 | 输入值 |  |  |  |
| ... | 整数 | 输入值 |  |  |  |
| 输入N | 整数 | 输入值 |  |  |  |

## 作用

把第一个输入按第二个输入指定的位数左移（<<），结果输出为整数。

移位量必须在 0 到 63 之间，否则运行时报错。

变长节点：连接器数量可增减，可通过界面 +/− 按钮或 CLI `program node connector add/delete` 调整。
