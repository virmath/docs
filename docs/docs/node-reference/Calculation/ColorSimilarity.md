# 颜色相似度

**节点类型**：`node-type:/Calculation/ColorSimilarity`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 颜色A | 整数 | 颜色值A | 相似度 | 浮点数 | 颜色相似度 |
| 颜色B | 整数 | 颜色值B |  |  |  |

## 作用

计算两个颜色值之间的相似度。

把两个颜色拆分为 ARGB 四个分量并归一化，计算两者的欧氏距离，相似度 = 1 − 距离 × 0.5，结果输出为浮点数。
