# 文本识别

**节点类型**：`node-type:/AI/Inference/OCR`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 文本识别引擎 | 文本识别引擎 | 文本识别引擎 | 结果 | JSON数组 | 识别结果 |
| 图像 | 图像 | 待识别图像 |  |  |  |
| 置信度 | 浮点数 | 置信度 |  |  |  |

## 作用

使用已加载的文本识别引擎对图像进行光学字符识别。

把图像送入引擎推理，按置信度阈值过滤识别区域，返回结果 JSON 数组。

结果数组中的每个元素为对象，包含 text（识别文本）、confidence（置信度，浮点数）和 bbox（四维浮点数向量，格式为 x、y、宽、高）。
