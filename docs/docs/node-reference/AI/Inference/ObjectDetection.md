# 对象检测

**节点类型**：`node-type:/AI/Inference/ObjectDetection`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ONNX | ONNX | ONNX 模型 | 结果 | JSON数组 | 检测结果 |
| 图像 | 图像 | 输入图像 |  |  |  |
| 区域 | 四维整数向量 | 待检测区域；x、y、z、w 全为 0 时使用全图 |  |  |  |
| 置信度 | 浮点数 | 置信度 |  |  |  |
| 交并比 | 浮点数 | IOU |  |  |  |

## 作用

使用 YOLO 系列 ONNX 模型对图像进行目标检测。

预处理时自动检查模型输入尺寸：若输入张量尺寸固定则缩放到该尺寸，否则按 32 的倍数补齐；推理后按置信度阈值过滤候选框，再按 IOU 阈值执行去重（NMS），最后按置信度降序返回结果。

「区域」使用 x、y、z、w 表示左边界、上边界、宽度和高度。x、y、z、w 全为 0 时使用完整图像；其余情况下 x、y 必须非负且宽度、高度必须大于 0，区域越界时节点报错。输出 bbox 坐标始终相对于原始完整图像。

结果是一个 JSON 数组，每个元素为对象，包含 class_id（整数）、bbox（四维浮点数向量：x、y 为左上角坐标，z、w 为宽、高）和 confidence（浮点数）。
