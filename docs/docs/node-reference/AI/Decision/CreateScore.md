# 创建评分题

**节点类型**：`node-type:/AI/Decision/CreateScore`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 题干 | 字符串 | 需要评分的问题 | 问题对象 | JSON对象 | 评分题对象 |
| 评分等级 N | 字符串 | 第 N 个评分级别，默认从 0 开始 |  |  |  |
| 等级说明 N | 字符串 | 第 N 个级别的说明，可留空 |  |  |  |

## 作用

创建一个评分题 JSON 对象。节点至少包含两个评分级别，可以通过节点底部的加减按钮增加或删除级别对，最多支持 10 个级别。

评分级别按连接器顺序从低到高发送，默认标签为 `0`、`1`，可以修改为其他字符串。

## 输出示例

```json
{
  "type": "score",
  "instructions": "当前紧急性有多高？",
  "levels": [
    {
      "label": "0",
      "description": "完全不紧急"
    },
    {
      "label": "1",
      "description": "非常紧急"
    }
  ]
}
```
