# 结构化问答

**节点类型**：`node-type:/AI/Decision/AnswerQuestions`

## 输入输出

| 输入名称 | 输入类型 | 输入说明                 | 输出名称 | 输出类型 | 输出说明             |
| -------- | -------- | ------------------------ | -------- | -------- | -------------------- |
| 上下文   | 字符串   | 提供给模型理解当前场景的上下文 | 回答列表 | JSON数组 | 按问题顺序排列的回答 |
| 问题列表 | JSON数组 | 由题目节点组成的题目数组 |          |          |                      |

## 作用

将状态和问题集发送到“设置 > 决策 API”中配置的后端，并返回结构化回答。

问题列表不能为空。选择题至少需要 2 个选项，评分题至少需要 2 个评分级别。
