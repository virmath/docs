# 创建选择题

**节点类型**：`node-type:/AI/Decision/CreateChoice`

## 输入输出

| 输入名称   | 输入类型 | 输入说明                  | 输出名称 | 输出类型 | 输出说明   |
| ---------- | -------- | ------------------------- | -------- | -------- | ---------- |
| 题干       | 字符串   | 需要选择的问题            | 选择题   | JSON对象 | 选择题对象 |
| 选项值 N   | 字符串   | 第 N 个选项的值           |          |          |            |
| 选项说明 N | 字符串   | 第 N 个选项的说明，可留空 |          |          |            |

## 作用

创建一个选择题，至少包含两个选项，可以通过节点底部的加减按钮增加或删除选项对。

选项值不能为空，且必须唯一。
