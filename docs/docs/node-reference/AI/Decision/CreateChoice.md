# 创建选择题

**节点类型**：`node-type:/AI/Decision/CreateChoice`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 题干 | 字符串 | 需要选择的问题 | 问题对象 | JSON对象 | 选择题对象 |
| 选项值 N | 字符串 | 第 N 个选项的值 |  |  |  |
| 选项说明 N | 字符串 | 第 N 个选项的说明，可留空 |  |  |  |

## 作用

创建一个选择题 JSON 对象。节点至少包含两个选项，可以通过节点底部的加减按钮增加或删除选项对，最多支持 255 个选项。

选项值不能为空。使用“执行决策”节点时，选项值必须唯一。

## 输出示例

```json
{
  "type": "choice",
  "instructions": "当前应该执行哪个操作？",
  "options": [
    {
      "value": "继续",
      "description": "保持当前流程"
    },
    {
      "value": "停止",
      "description": "终止当前程序"
    }
  ]
}
```
