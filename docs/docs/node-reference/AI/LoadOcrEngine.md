# 加载文本识别引擎

**节点类型**：`node-type:/AI/LoadOcrEngine`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| 文本检测模型 | 字符串 | 文本检测模型路径 | 文本识别引擎 | 文本识别引擎 | 文本识别引擎 |
| 文本识别模型 | 字符串 | 文本识别模型路径 |  |  |  |
| 字符字典 | 字符串 | 字符字典路径 |  |  |  |

## 作用

加载文本识别（OCR）引擎。依次读取文本检测模型、文本识别模型和字符字典三个文件路径，按当前推理后端与设备加载模型，加载成功后输出一个文本识别引擎对象。
