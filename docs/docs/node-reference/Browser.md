浏览器节点：启动浏览器并操作网页，支持快照定位元素、点击、输入与等待。

元素引用（`@e3`）由「页面快照」节点产生；「目标」输入也可以直接填写 CSS 选择器、`text=` 或 XPath。编辑器为这些「目标」输入提供了元素选择器：点击输入框右侧按钮后，会打开一个预览浏览器加载页面，再从元素列表中选择（写入可跨运行复用的 `text=` 选择器），或写入只在本次运行有效的元素引用。

分组如下：

- `Browser/Session`：启动、连接、关闭浏览器，以及标签页管理。
- `Browser/Navigation`：打开网址、设置视口。
- `Browser/Read`：页面快照、获取文本、查找文本、页面信息、截图、执行 JavaScript。
- `Browser/Action`：点击、输入、选择选项、处理对话框、等待、悬停、按键、滚动、拖拽、拖放、填写表单、上传文件。
- `Browser/Diagnostics`：控制台日志、网络请求列表与请求详情。

「悬停」「按键（填了目标时）」「滚动（填了目标时）」「拖拽」「拖放」「填写表单」的「目标」只支持元素引用（`@e3`），请先用「页面快照」节点取得引用；这些节点不接受 CSS/XPath 选择器。

## 元素选择器对话框

点击「目标」输入框右侧的按钮会打开预览浏览器，填入网址并点「加载元素」后：

- 左侧是当前页面的视口截图，页面里可交互的元素会以蓝框标出。点一下方框即可选中对应元素，选中的元素框会变成橙色，同时右侧列表会滚动到它。
- 右侧列表列出快照里的全部元素（包含当前视口外的元素），可以用「搜索」过滤，也可以直接点击选择。过滤同样会过滤左侧的元素框。
- 「使用文本」写入 `text=名称`，这种选择器可以跨运行复用。
- 「使用 CSS 选择器」为选中元素生成唯一的 CSS 选择器（优先用 `id`，其次用 `data-testid`/`name`/`aria-label` 等属性，最后退化成带 `:nth-of-type` 的层级路径），并直接写入结果。
- 「使用 XPath」为选中元素生成唯一的 XPath（优先用 `//*[@id=...]`，其次用属性，最后退化成带位置的层级路径），适合目标节点只接受 XPath 的场景。
- 也可以在手填框里自己写 CSS/XPath 选择器，再点「写入手填值」。

预览浏览器用无头模式打开时不会弹出窗口，取消勾选即可看到实际页面，方便排查加载失败、需要登录等问题。
