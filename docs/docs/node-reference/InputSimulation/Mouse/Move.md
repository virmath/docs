# 移动

**节点类型**：`node-type:/InputSimulation/Mouse/Move`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 位置 | 二维整数向量 | 目标位置 |  |  |  |
| 移动模式 | 整数 | 移动模式 |  |  |  |
| 时长 | 整数 | 移动时长（毫秒） |  |  |  |

## 作用

把鼠标移动到指定位置。

位置为二维整数向量；移动模式（Raw/绝对/相对等）由 移动模式 输入指定。

时长为 0 时立即移动到目标位置；时长大于 0 时在指定时长内逐步移动，形成平滑的移动轨迹，时长越长移动越慢。
