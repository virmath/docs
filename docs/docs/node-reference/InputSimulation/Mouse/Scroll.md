# 滚轮（鼠标 / 滚动）

**节点类型**：`node-type:/InputSimulation/Mouse/Scroll`

## 输入输出

| 输入名称 | 输入类型 | 输入说明 | 输出名称 | 输出类型 | 输出说明 |
| --- | --- | --- | --- | --- | --- |
| ➡️ | 流程控制 | 执行流入口 | ➡️ | 流程控制 | 执行流出口 |
| 长度 | 整数 | 滚动距离 |  |  |  |
| 横向 | 布尔 | 水平滚动 |  |  |  |

## 作用

模拟鼠标滚轮滚动。

长度 为滚动距离；横向 为真时水平滚动，为假时垂直滚动。
