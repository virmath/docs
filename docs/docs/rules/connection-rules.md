# 连接规则

本文档介绍节点编辑器中节点连线（连接）的校验与行为规则。

## 连接前置条件

尝试连接两个端口时，满足以下任一条件即直接拒绝：

| 条件 | 说明 |
| --- | --- |
| 同一端口 | 端口不能与自身连接 |
| 同一节点 | 同一节点内部的端口不能互相连接 |
| 用途相同 | 输入端不能连接输入端，输出端不能连接输出端 |
| 端口被禁用 | 任一端口处于禁用状态（例如运行时只读端口） |

## 方向规则

- 连线方向统一为「输出端 → 输入端」：即使从输入端开始拖拽到输出端，最终也会规范为从输出端指向输入端。
- 输入端口同一时刻只能拥有一条连线；建立新连线前，会自动移除该输入端口上已有的连线（替换式连接），替换操作可以整体撤销。
- 输出端口可以同时连接多个输入端口。

## 数据类型匹配规则

数据类型匹配按顺序检查，命中即允许；全部未命中时拒绝连接，并弹出「数据类型不匹配」错误提示。

### 端口类型分组

| 分组 | 包含的端口类型 |
| --- | --- |
| 流程控制 | 流程控制（➡️） |
| 数值 | 整数、浮点数 |
| 二维向量 | 二维整数向量、二维浮点数向量 |
| 四维向量 | 四维整数向量、四维浮点数向量 |
| JSON 数据 | 布尔、整数、浮点数、字符串、JSON值、JSON数组、JSON对象、二维向量、四维向量 |
| 原生对象 | 图像、ONNX、文本识别引擎、视频流 |

### 匹配规则

| 输出端 | 输入端 | 结果 |
| --- | --- | --- |
| 流程控制 | 流程控制 | ✔ 允许 |
| 流程控制 | 其他任意 | ✘ 拒绝 |
| 其他任意 | 流程控制 | ✘ 拒绝 |
| 数值 | 数值 | ✔ 允许（整数与浮点数可互连） |
| 二维向量 | 二维向量 | ✔ 允许（整数与浮点分量可互连） |
| 四维向量 | 四维向量 | ✔ 允许 |
| JSON 数据（任意） | JSON值 | ✔ 允许 |
| JSON值 | JSON值、整数、浮点数、字符串、布尔、JSON数组、JSON对象、二维向量、四维向量 | ✔ 允许（运行时检查数据兼容性，不匹配将报错） |
| 原生对象 | 原生对象 | ✔ 允许（见「原生对象子类型规则」） |
| 其他组合 | 其他组合 | 见「通用回退规则」 |

### 通用回退规则

未命中上述任何规则时，按输出端口与输入端口的数据类型判断：

1. 输入端口数据类型为字符串 → 允许任意输出端口连接。
2. 输出端口与输入端口的数据类型相同 → 允许。
3. 其余情况 → 拒绝。

该检查针对端口**数据类型**进行，典型效果：

- 任意输出 → 字符串输入：一律允许。
- 字符串输出 → 数值、向量等输入：拒绝。
- 布尔 → 布尔、字符串 → 字符串、JSON对象 → JSON对象、JSON数组 → JSON数组：数据类型相同，允许。

### 原生对象子类型规则

两个端口均为原生对象类型时，进一步按输入端口声明的原生对象子类型与原生对象特征判断：

| 输入端口状态 | 规则 |
| --- | --- |
| 子类型未指定且未要求任何特征 | 允许 |
| 子类型未指定但要求某些特征 | 要求输出端口的原生对象子类型也具备这些特征，否则拒绝 |
| 子类型已指定 | 要求与输出端口原生对象子类型完全相同，否则拒绝 |

当前定义的原生对象特征有：

| 特征 | 说明 |
| --- | --- |
| 可获取长度 | 对象具有长度属性（如字节序列） |
| 可转为字符串 | 对象可转换为字符串 |
| 可读取帧 | 对象可逐帧读取（如视频流） |

例如：输入端口原生对象子类型未指定但要求「可读取帧」时，只有具备该特征的对象（如视频流）可以连接；图像不具备该特征，因此不能连接。

## 常见组合示例

| 组合 | 结果 | 依据 |
| --- | --- | --- |
| 整数 → 浮点数 | ✔ | 同属数值分组 |
| 整数 → JSON值 | ✔ | JSON 数据输出可连接 JSON值 输入 |
| JSON值 → 整数 | ✔ | JSON值 输出可连接数值输入 |
| 二维整数向量 → 二维浮点数向量 | ✔ | 同属二维向量分组 |
| 整数 → 字符串 | ✔ | 字符串输入接受任意输出 |
| 字符串 → 整数 | ✘ | 字符串不属于数值分组 |
| 图像 → 文本识别引擎 | ✘ | 原生对象类型不同 |
| 视频流 → 视频流 | ✔ | 原生对象类型相同 |

## 说明

以上规则为当前版本的行为，后续版本可能调整。
