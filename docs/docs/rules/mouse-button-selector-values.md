# 鼠标按钮选择器可选值

鼠标按钮选择器（MouseButtonSelector）支持的值是鼠标按钮的英文名称，可直接用于 `option set` / `connector set` 的值参数，也可在编辑器中通过按钮监听自动获取。值区分大小写。

| 值 | 整数值 | 说明 |
| --- | --- | --- |
| `LeftButton` | 1 | 左键 |
| `RightButton` | 2 | 右键 |
| `MiddleButton` | 3 | 中键 |
| `BackButton` | 4 | 后退键 |
| `ForwardButton` | 5 | 前进键 |
| `Undefined` | 0 | 未定义（默认值），一般无需手动设置 |
